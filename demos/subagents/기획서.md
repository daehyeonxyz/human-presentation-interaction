# 서브에이전트와 병렬 작업 — 기획서

## 기획

- 목적: human-presentation-interaction 스킬의 검증 덱 1호다. 가변 폭 스테이지와 호버 반응 규격과 미검증 판 point-map 을 실전 제작으로 검증한다.
- 청중: Claude Code 를 쓰는 개발자. 세미나 결이라 인쇄 층은 명사형 종결과 반말 평서를 쓴다.
- 결론 한 줄: 서브에이전트는 메인 컨텍스트를 지키면서 여러 갈래 작업을 동시에 진행하는 도구다.
- 발표 시간: 데모용 7쪽. 시간 게이트는 적용하지 않는다.

## 구성 (판 지도)

| 쪽 | 핵심 메시지 | 판 ID | 등급 | 근거 |
|---|---|---|---|---|
| 1 | 표지 | `cover-stage` | 0 | 조작 없음 |
| 2 | 서브에이전트를 쓰는 이유는 세 가지다 | `pick-list` | 1 | 상세를 숨겨 인지 부하를 줄인다 |
| 3 | 위임하면 메인 컨텍스트가 지켜진다 | `advance-machine` | 2 | 컨텍스트가 차오르는 변화 자체가 메시지다 |
| 4 | 병렬 디스패치는 동시에 진행된다 | `simulate-console` | 3 | 시스템의 동작 자체가 메시지라 재생과 탐색이 필요하다 |
| 5 | 순차와 병렬은 걸린 시간이 다르다 | `pick-contrast` | 2 | 대비가 메시지라 두 블록의 상태 전환이 필요하다 |
| 6 | 위임 프롬프트에는 구조가 있다 | `point-map` | 2 | 예문과 규칙의 대응 관계가 메시지다. 미검증 판의 첫 실물이다 |
| 7 | 정리 | `accumulate-recap` | 1 | 되짚기와 선언 |

## 채널 배분

- 말: 각 쪽의 배경 설명과 전환.
- 인터랙션: 3쪽 게이지 변화, 4쪽 병렬 진행 시뮬레이션, 5쪽 타임라인 전환, 6쪽 대응 강조.
- 텍스트: 각 쪽의 주장 한 줄과 맺음 문장.

## 근거

- 수치는 전부 시뮬레이션 예시이고 화면에 (예시) 를 표기한다.
- 개념 근거는 Claude Code 공식 문서의 서브에이전트 동작이다.
