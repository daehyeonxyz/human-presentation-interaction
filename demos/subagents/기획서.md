# 서브에이전트와 병렬 작업 — 기획서

## 기획

- 목적: human-presentation-interaction 스킬의 검증 덱 1호다. 가변 폭 스테이지와 호버 반응 규격과 미검증 판 point-map 을 실전 제작으로 검증한다.
- 청중: Claude Code 를 쓰는 개발자. 세미나 결이라 인쇄 층은 명사형 종결과 반말 평서를 쓴다.
- 결론 한 줄: 서브에이전트는 메인 컨텍스트를 지키면서 여러 갈래 작업을 동시에 진행하는 도구다.
- 발표 시간: 데모용 7쪽. 시간 게이트는 적용하지 않는다.

## 구성 (판 지도와 셀 지도)

레이아웃 패턴은 원본 택소노미(`references/taxonomy.md`)의 ID 로 지목한다. 조작 문법은 `interaction-grammar.md` 의 `g-*` 다.

| 쪽 | 핵심 메시지 | 레이아웃 패턴 | 조작 문법 | 등급 | 근거 |
|---|---|---|---|---|---|
| 1 | 표지 | `oversized-type` + `swiss-grid` | `g-none` | 0 | 조작 없음 |
| 2 | 서브에이전트를 쓰는 이유는 세 가지다 | `hierarchical-grid` + `modular-grid` | `g-none` | 0 | 세 항목은 정지 화면으로 증명된다. 클릭 공개는 논증에 기여하지 않아 강등했다 |
| 3 | 위임하면 메인 컨텍스트가 지켜진다 | `bento-grid` + `asymmetric-two-up` | `g-advance` · `g-pin` | 2 | 컨텍스트가 차오르는 변화 자체가 메시지다 |
| 4 | 병렬 디스패치는 동시에 진행된다 | `bento-grid` + `asymmetric-two-up` + `stat-band` | `g-advance` · `g-pin` | 3 | 시스템의 동작 자체가 메시지라 재생과 탐색이 필요하다. 시간 대비 결론까지 이 쪽이 증명한다 |
| 5 | 위임 프롬프트에는 구조가 있다 | `modular-grid` + `spatial-grouping` | `g-point` · `g-pin` | 2 | 예문과 규칙의 대응 관계가 메시지다 |
| 6 | 정리 | `hierarchical-grid` + `oversized-type` | `g-advance` | 1 | 되짚기와 선언 |

### 셀 지도

프레임은 여백 80 안쪽의 12열 격자다. 면을 갖는 셀과 배경 위에 놓는 셀을 함께 적는다.

| 쪽 | 셀 | 면 |
|---|---|---|
| 1 | 머리 행 오른쪽 영문 / 본체 큰 제목 / 바닥 왼쪽 태그라인과 오른쪽 표기 | 전부 배경 위 |
| 2 | 1~4열 표제 · 5~12열 항목 셋 | 표제는 배경 위, 첫 항목은 흰 면, 나머지 둘은 우물 면 |
| 3 | 표제 행 전폭 · 1~9열 장치(머리 · 단계 라벨 넷 · 게이지 둘과 캡션 둘 · 조작부 · 맺음) · 10~12열 곁 열(머리와 단계별 항목 넷) | 장치만 흰 면, 맺음은 그 안의 우물 면, 곁 열은 배경 위이고 호버에서만 면이 뜬다 |
| 4 | 표제 행 전폭 · 1~8열 조작 창(머리 · 트랙 셋과 부연 셋 · 조작부 · 맺음) · 9~12열 관찰 창(상시 표시 · 보고 목록 · 인스펙터에 작업 내용과 수치 둘) | 조작 창은 흰 면, 관찰 창은 우물 면, 보고 항목과 인스펙터는 그 안의 흰 면 |
| 5 | 표제 행 전폭 · 네 행 각각 1~8열 예문 구획과 9~12열 규칙(이름과 부연) · 다섯째 행 전폭 맺음 | 예문은 흰 면, 규칙은 배경 위, 맺음은 우물 면 |
| 6 | 1~5열 선언과 다음 물음 · 6~12열 되짚기 여섯(이름과 부연) | 선언과 다음 물음은 배경 위, 되짚기는 우물 면이고 켜지면 흰 면 |
## 왕복 기록

- 2026-08-28 사용자 반려로 구조를 개정했다. 반려 사유는 세 가지다: 의미 없는 인터랙션이 많다, 서술이 AI 상투 문형이다, 아래 여백이 몇백 px 남는다.
- 옛 2쪽(pick-list)은 조작이 메시지를 증명하지 않아 등급 0 정지로 강등했다.
- 옛 5쪽(순차·병렬 시간 대비)은 4쪽 시뮬레이션이 이미 증명하는 내용이라 버리고 그 결론 수치를 4쪽 맺음으로 옮겼다. 일곱 쪽이 여섯 쪽이 됐다.
- 원고의 맺음 문장 전부를 대구 경구에서 화면의 구체 수치 요약으로 다시 썼다.

## 채널 배분

- 말: 각 쪽의 배경 설명과 전환.
- 인터랙션: 3쪽 게이지 변화, 4쪽 병렬 진행 시뮬레이션, 5쪽 타임라인 전환, 6쪽 대응 강조.
- 텍스트: 각 쪽의 주장 한 줄과 맺음 문장.

## 근거

- 수치는 전부 시뮬레이션 예시이고 화면에 (예시) 를 표기한다.
- 개념 근거는 Claude Code 공식 문서의 서브에이전트 동작이다.
