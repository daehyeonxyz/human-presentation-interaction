Input · Output · Repetition

입력 토큰 시스템 프롬프트와 도구 정의와 지난 대화 전부가
요청마다 입력으로 다시 들어간다
출력 토큰 모델이 새로 만든 글자. 단가가 입력보다 높다
반복 전송 대화가 길어질수록 같은 앞부분을
매번 다시 보내는 비중이 커진다

반복 전송이 커지는 구조가 캐싱이 노리는 표적

Hit rate · Input cost

캐시 적중률 0%
하루 입력 비용 (예시) 100

적중 0%면 100 / 적중 100%면 대략 10 (예시)
