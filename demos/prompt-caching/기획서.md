# 프롬프트 캐싱과 비용 — 기획서

## 기획

- 목적: 검증 덱 2호다. 택소노미에서 규격만 있고 실물이 없는 세 판(drag-compare, drag-threshold, input-sandbox)을 실전 제작으로 검증한다.
- 청중: LLM API 를 쓰는 개발자. 세미나 결이라 인쇄 층은 명사형 종결과 반말 평서를 쓴다.
- 결론 한 줄: 같은 접두사를 다시 보내는 구조를 만들면 캐시가 입력 비용을 대부분 지운다.
- 발표 시간: 데모용 6쪽. 시간 게이트는 적용하지 않는다.

## 구성 (판 지도)

| 쪽 | 핵심 메시지 | 판 ID | 등급 | 근거 |
|---|---|---|---|---|
| 1 | 표지 | `cover-stage` | 0 | 조작 없음 |
| 2 | 비용은 세 곳에서 쌓인다 | `pick-list` | 1 | 상세를 숨겨 인지 부하를 줄인다 |
| 3 | 캐시는 요청의 앞부분을 저장한다 | `drag-compare` | 2 | 캐시 유무의 대비를 한 화면에서 겹쳐 봐야 한다. 미검증 판의 첫 실물 |
| 4 | 같은 접두사로 보내야 적중한다 | `input-sandbox` | 3 | 요청을 직접 보내 보는 체험이 메시지다. 미검증 판의 첫 실물 |
| 5 | 적중률이 비용을 정한다 | `drag-threshold` | 2 | 값을 끌면 비용이 바뀌는 관계 자체가 메시지다. 미검증 판의 첫 실물 |
| 6 | 정리 | `accumulate-recap` | 1 | 되짚기와 선언 |

## 채널 배분

- 말: 각 쪽의 배경 설명과 전환.
- 인터랙션: 3쪽 겹침 핸들, 4쪽 요청 전송 재현, 5쪽 적중률 슬라이더.
- 텍스트: 각 쪽의 주장 한 줄과 맺음 문장.

## 근거

- 수치는 전부 시뮬레이션 예시이고 화면에 (예시) 를 표기한다. 실제 단가를 주장하지 않는다.
- 개념 근거는 Anthropic API 문서의 prompt caching 동작이다.
