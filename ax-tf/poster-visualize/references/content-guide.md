# content.json 작성 기준

포스터는 위에서 아래로 머리, 장 여러 개, 맨 끝 문의 줄 순서다. 머리와 장 안에는 블록을 골라 쌓는다.
예시 json 세 개(`examples/`)가 블록을 거의 다 쓰므로, 비슷한 예시를 복사해 고치는 것이 가장 빠르다.

## 글자 서식

모든 문장 칸에 쓸 수 있다.

| 쓰는 법 | 결과 | 쓰는 곳 |
|---|---|---|
| `**굵게**` | 굵은 글씨 | 문장 안의 핵심 낱말 하나 |
| `*강조*` | 강조색(남색) | 제목에서 가장 중요한 말 하나 |
| `{2026년 10월 30일 (금)}` | 남색 배지 | 마감일처럼 놓치면 안 되는 날짜 |
| `[[○월 ○일]]` | 노란 표시 | 아직 정하지 않은 값. 보내기 전에 채운다 |
| `\n` | 줄바꿈 | 뜻 덩어리가 끝나는 곳에서 바꾼다 |

이모지(🥇, 🚨 등)는 그대로 쓰면 이모지 글꼴로 그려진다. 공지 대상이 실제로 쓰는 표시일 때만 쓴다.

## 머리

| 칸 | 내용 |
|---|---|
| `title` | 브라우저 탭 이름. 비우면 제목을 쓴다 |
| `label` | 제목 위 작은 줄. 소식지나 행사 이름(예: `삼성벤처투자 AX 소식`) |
| `headline` | 제목 한 줄. 96px 에서 넘치면 84px 까지 자동으로 줄이고, 그래도 넘치면 고칠 곳으로 나온다 |
| `intro` | 제목 아래 회색 한 줄 소개. 선택 |
| `hero` | 맨 위 그림. 아래 세 종류 중 하나. 없으면 생략 |
| `hero_lead` | 그림 아래 큰 문장 한두 줄. 공지 전체를 한 문장으로 말한다 |
| `facts` | 개요 칸 `[["이름표", "값"], ...]`. 짝수 개로 둔다(2열) |
| `hero_blocks` | 머리 끝에 더 붙일 블록 목록. 공모전의 평가 기준처럼 장 제목 없이 이어질 때 |
| `numbered` | 장 제목 앞 번호(1. 2. 3.) 사용 여부. 기본 `true` |
| `foot` | 맨 아래 문의 줄. 회색 작은 글자로 오른쪽에 붙는다 |

### hero 종류

```json
{"type": "podium", "places": [
  {"rank": 1, "rank_label": "🥇 1위", "main": "홍길동"},
  {"rank": 2, "main": "30", "unit": "만원"}]}
```
- 시상대 그림 위 1·2·3위 블록에 글자를 얹는다. `main` 은 상금 숫자나 이름, `unit` 은 작은 단위, `rank_label` 은 위 작은 줄이다.
- `rank_label` 이 하나라도 있으면 그림이 조금 아래로 내려가 자리가 생긴다.

```json
{"type": "stack", "images": ["shot1.jpg", "shot2.jpg"], "height": 1680}
```
- 화면 캡처나 문서 쪽을 엇갈려 세우고 아래를 흐린다. 그림 경로는 content.json 기준이다.
- 두 장 이하는 820px 폭으로 나란히, 세 장 이상은 660px 폭으로 겹쳐 세운다. `width`, `dx`, `dy` 로 바꿀 수 있다.
- `height` 는 보이는 높이다. 화면을 충분히 보여 주려면 1400~1700 을 준다.

```json
{"type": "image", "src": "visual.png"}
```
- 그림 한 장을 1760 폭으로 넣는다.

## 장

```json
{"title": "뉴스레터 구성", "lead": "설명 한두 줄", "blocks": [ ... ]}
```
- 좌우 두 칸으로 나눌 때는 `{"split": [{"title": ..., "lead": ..., "blocks": [...]}, {...}]}` 로 쓴다. 번호는 칸마다 하나씩 붙는다.
- `blocks` 가 빈 장은 제목과 설명만 남는다. 맺음 장에 쓴다.

## 블록

| type | 쓰는 곳 | 주요 칸 |
|---|---|---|
| `text` | 문단 하나 | `text` |
| `subhead` | 장 안의 작은 제목 | `text` |
| `facts` | 이름표와 값. `style: "card"` 면 카드 한 장 안에 줄로 쌓고 아래에 `note` | `items`, `style`, `note` |
| `cards` | 2~4열 카드 | `cols`, `items[]` (아래) |
| `flow` | 단계 흐름 2~4개. 사이에 화살표 | `items[]` (아래) |
| `stats` | 팀별 수치처럼 같은 형식의 숫자 카드 | `items[].name`, `items[].rows: [["이름표","숫자","단위"]]` |
| `band` | 포스터 폭 전체를 채우는 남색 띠. 한 장에 한 번 | `title`, `text` |
| `stack` | 장 안의 엇갈린 그림 | hero 의 stack 과 같고 `label` 을 더 쓸 수 있다 |
| `files` | 폴더와 파일 목록 카드 | `name`, `items: [["경로","역할"]]` |
| `chat` | Claude 채팅창 | `model`(필수), `messages[]`, `input`, `height`, `title` |
| `chats` | 채팅창 두 개를 나란히 | `items: [chat, chat]` |
| `html` | 위 블록으로 안 되는 화면. poster.css 의 클래스를 쓴다 | `html` |

### cards 의 항목

| 칸 | 내용 |
|---|---|
| `title` | 카드 제목 |
| `accent` | 제목 앞 강조색 글자(예: `50%`, 번호) |
| `right` | 제목 줄 오른쪽 강조색 글자(예: 상금) |
| `text` | 본문 |
| `chips` | 카드 아래 칩 목록 |
| `msg` | 말풍선. 받는 사람이 보낼 법한 실제 요청 예시 |
| `tiles` | 분류 칸 `[{"label": "🚨 CRITICAL", "tone": "crit", "items": [...]}]`. tone 은 `acc`, `crit`, `ink`, `mute` |

### flow 의 항목

```json
{"title": "명단과 키워드 입력", "text": "한 줄 설명", "parts": [
  {"caption": "포트폴리오 명단"},
  {"table": {"head": ["업체", "담당 심사역"], "rows": [["A사", "홍길동"]]}},
  {"rows": ["뉴스와 공시 수집", "중요도 분류와 요약"]},
  {"rows": [{"text": "[투자3팀] 포트폴리오 뉴스", "sub": "🚨2 · ⚡1"}]}]}
```
- 세 패널의 제목과 설명은 같은 높이에 놓이고, 그림 부분은 같은 높이에서 시작한다.
- `rows` 는 남는 높이를 칸이 나눠 가져서 패널 아래 끝이 맞는다. 표가 가장 긴 패널이 높이를 정한다.
- 설명은 한 줄로 쓴다. 세 패널일 때 한글 18자 안팎이다.

### chat 의 메시지

| 칸 | 내용 |
|---|---|
| `role` | `user` 또는 `assistant` |
| `text` | 본문. `/스킬이름` 은 파란 글자로 보인다 |
| `attach` | 사용자 메시지 위 첨부 파일 이름 |
| `skill` | 답에 "스킬 사용" 줄을 붙인다 |
| `file` | 답 아래 결과 파일 카드 |
| `done` | `true` 면 흐리게. 이미 지난 대화를 보여 줄 때 |

- `input.text` 를 넣으면 입력창에 쓰는 중인 문장으로 보이고, `input.hot: true` 면 입력창에 주황 링이 생긴다. 지금 보낼 문장을 가리킬 때 쓴다.
- `model` 은 이 요청을 실제로 쓸 때 고르는 모델 이름을 Claude 앱 표기 그대로 쓴다. 모르면 사용자에게 묻는다.

## 검사 항목

`build.py` 는 아래를 어기면 고칠 곳으로 출력하고 HTML 을 만들지 않는다.

- 제목이 84px 로도 한 줄에 들어가지 않는다
- 소개, 큰 문장, 장 설명, 띠 문장의 한 줄이 포스터 폭을 넘는다
- 띠가 두 개 이상이다
- 그림 파일이 없다
- 채팅창에 `model` 이 없다
- 모르는 블록 종류를 썼다

아직 채우지 않은 `[[...]]` 값과 홀수 개 개요 칸은 주의로만 출력한다.
`capture.py` 는 캡처한 화면에서 제목, 카드 머리, 표 칸 등이 넘친 곳을 찾아 출력한다.
