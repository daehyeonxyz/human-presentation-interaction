# human-presentation-interaction

청중이 직접 보고 조작하며 이해하게 되는 발표 자료를 기획부터 구현과 검증까지 만드는 스킬이다. 산출물은 빌드 없이 file:// 로 열리는 zero-dependency 단일 HTML 이고, 개념을 도형 몇 개로 그리는 대신 그 개념에 어떤 인터랙션이 필요한지 먼저 판정하고 실제로 구동되는 구현체 수준까지 만든다.

## 구성

| 경로 | 내용 |
|---|---|
| `SKILL.md` | 실행 절차의 단일 원본. 기획부터 검증까지 10단계 |
| `layout-taxonomy.md` | 레이아웃 분류 체계. 조작 문법 8종과 논리 구조 9종의 교차로 판 16종을 정의한다 |
| `research/` | 지향점과 발표 철학과 인터랙션 방법론 조사 |
| `demos/` | 스킬 검증 덱. 주제별 폴더에 기획서와 원고와 산출물과 QA 증거가 있다 |
| `ax-education/` | 실전 발표 프로젝트 |
| `qa/fluid-gate.mjs` | 해상도 매트릭스 게이트. 레포의 모든 덱을 다섯 해상도에서 검사한다 |

## 스테이지 계약

- 세로는 1080 기준 배율로 뷰포트 높이에 맞추고, 가로는 네 변 여백 80 을 고정한 채 무대 폭이 뷰포트를 채운다. 폭의 하한은 1920 이고 상한은 2560 이다.
- 좌우 키는 쪽 넘김이고 Space 는 그 쪽의 다음 조작이고 End 는 완료 상태다. 완료된 쪽에서 Space 는 처음 상태로 되돌린다.
- 커서가 pointer 인 요소는 전부 호버 반응을 낸다. 호버 미리보기가 있는 곳에는 클릭 고정이 함께 있다.
- 모든 판은 안정성 가드레일 열 가지(넘침 제어, 칸 예약, 위치 이동 금지, 키보드 복구, 호버 반응, 정적 폴백, 쪽 되돌림 등)를 지킨다.

## 검증

```bash
node qa/fluid-gate.mjs
```

deliverables 폴더의 덱을 자동으로 찾아 다섯 해상도(4:3, 16:10, 16:9, 21:9 두 가지)에서 스테이지 폭 계산과 렌더 배율과 여백 유지와 네 변 넘침과 호버 전수 반응과 키보드 계약을 검사한다. 덱마다 `qa/` 에 렌더 캡처와 조작 관찰 증거가 남는다.

## 데모 덱

| 덱 | 주제 | 검증한 것 |
|---|---|---|
| `demos/subagents` | 서브에이전트와 병렬 작업 | 가변 폭 스테이지, point-map 판 첫 실물 |
| `demos/prompt-caching` | 프롬프트 캐싱과 비용 | drag-compare · drag-threshold · input-sandbox 판 첫 실물 |

덱의 수치는 전부 시뮬레이션 예시이고 화면에 예시 표기가 있다.
