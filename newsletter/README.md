# 사내 뉴스레터 · 이메일 판

`ax-education/디자인.md` 와 `tokens.css` 의 값을 이메일 HTML 로 옮긴 실물이다. 슬라이드 스테이지가 아니라 메일 클라이언트에서 열리는 산출물이라 `SKILL.md` 의 10단계는 적용하지 않고, 색·서체·층·위계 규칙만 가져왔다.

## 가져온 규칙

- 면 세 층. 배경 `#E5E9F1` 위에 흰 카드, 카드 안의 관점 상자는 `#F1F4F9`. 카드 둘레 테두리와 그림자는 없다.
- 강조는 파랑 하나. 상징 `#1428A0`, 강조 `#0361E4`. 등급 구분은 색상을 늘리지 않고 CRITICAL 만 판정색 `#C9352B`, 나머지는 파랑 두 단과 회색 `#737373` 으로 가른다.
- 등급을 알약 배지로 찍지 않는다. 굵기와 색만으로 표시한다.
- 글 덩이는 머리(굵은 한 줄)로 시작하고 몸과 딸림이 뒤따른다. 구역 제목은 본문보다 확실히 크다.
- radius 는 16 / 12 / 10 / 6 넷만 쓴다.

## 이메일 제약으로 바꾼 것

- 레이아웃은 전부 `<table>` 이고 스타일은 인라인이다. CSS 변수와 외부 서체를 쓰지 않는다.
- 서체는 `Pretendard, Apple SD Gothic Neo, Malgun Gothic, Samsung One Korean` 폴백 사슬이다.
- 폭 680, 한글 어절은 `word-break: keep-all` 로 지킨다.
