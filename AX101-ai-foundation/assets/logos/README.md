# 로고

2장 "인공지능 서비스"의 타일 세 칸에 들어갈 ChatGPT · Gemini · Claude 로고 자리다.

- 서드파티 브랜드 자산이라 **직접 그리지 않는다.** 각 사의 공식 브랜드 페이지에서 받은 SVG 또는 PNG(높이 96 이상)를 이 폴더에 둔다
- 파일 이름: `chatgpt.svg` · `gemini.svg` · `claude.svg`
- 받지 못하면 타일은 이름만 `--font-display` 40/700으로 찍는다. 이것이 현재 기본값이고 화면에 빈자리가 남지 않는다
- 로고를 넣을 때 타일 안 배치: 왼쪽 48px 로고 · 간격 16 · 이름 · 아래 회사명 20/500 `--ink-support`
