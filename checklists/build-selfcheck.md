# 구현 자가 점검표

8단계 구현을 마친 뒤 코드와 대조한다. 전 항목 통과가 8단계의 통과 기준이다. 이 표는 관찰을 대신하지 못한다. 관찰 앞에서 걸러 내는 그물이다.

항목마다 **어떻게 확인하는가**가 붙어 있다. 눈으로 훑어 "그럴 것이다" 로 통과시키지 않는다.

## 값

- [ ] `:root` 가 루트 `tokens.css` 사본에 프로젝트 강조색을 이어 붙인 형태다 — 두 파일을 나란히 놓고 선언을 대조한다
- [ ] 강조색 말고 다시 적은 값이 없다 — 프로젝트 `tokens.css` 에 `--acc`·`--acc-soft`·`--n1`~`--n7` 밖의 선언이 없다
- [ ] 글자 크기가 사다리 여덟 단 안에 있다 — `font-size:` 를 전수 검색해 `--t-` 토큰이 아닌 px 값이 제품 재현 블록 밖에 없는지 본다
- [ ] 간격이 사다리 일곱 값 안에 있다 — `gap:`·`padding:`·`margin:` 을 전수 검색한다
- [ ] radius 가 `--r-card`·`--r-ctl`·`--r-dot` 과 `50%`·`999px` 밖에 없다
- [ ] 그림자가 `--shadow` 하나뿐이다 — 층을 그림자로 만들지 않았다

## 무대 계약

- [ ] 배율이 `min(vw/1920, vh/1080)` 이고 설계 크기가 1920x1080 고정이다 — `fit()` 의 식을 그대로 읽어 대조한다
- [ ] 레터박스를 감추지 않고 그 쪽의 캔버스 색으로 둔다 — `.viewport` 가 `.dark`·`.blue` 를 쪽에서 물려받는다
- [ ] 네 변 여백이 정확히 80 이다 — `.s` 의 `padding` 이 `var(--pad)` 하나다
- [ ] 본체가 `flex: 1` 이라 아래가 남지 않는다
- [ ] `transform` 을 스테이지 배율과 `data-morph` 말고 배치에 쓰지 않았다 — `transform:` 을 전수 검색해 확인한다

## 넘김 계약

- [ ] 좌우 키가 쪽 넘김이다
- [ ] `Space` 와 화면 클릭이 그 쪽의 다음 단계 하나다. 두 현상이 한 번에 일어나지 않는다
- [ ] 고르는 부품과 링크가 클릭 전파를 낚아 쪽을 넘기지 않는다 — 각 핸들러에 `e.stopPropagation()` 이 있다
- [ ] 자기 할 일이 끝난 부품은 전파를 낚지 않는다 — 한 번 쓰고 나면 그 자리가 죽은 영역이 되지 않는다
- [ ] 글자를 끌어 고르는 중에는 넘어가지 않는다
- [ ] 처음 쪽과 끝 쪽에서 더 눌러도 그 쪽이 되감기지 않는다
- [ ] 조작 뒤 초점이 풀려 방향키가 즉시 듣는다 — 모든 조작 핸들러 끝에서 초점을 놓는다
- [ ] `Enter` 로도 초점이 놓인 조작이 실행된다
- [ ] 처음부터 끝까지 마우스 없이 진행된다 — 마우스로만 닿는 조작이 하나도 없다

## 공용 API (게이트가 전제한다)

- [ ] 쪽이 `.s` 이고 `window.STAGE.version` 이 2 다
- [ ] `window.go(n)` 이 쪽 번호와 같은 1 기반이다
- [ ] `window.still()` 이 등장 애니메이션을 정지시킨다
- [ ] `window.finish()` 가 그 쪽의 완료 상태이고 되풀이해 불러도 같은 화면이다
- [ ] `window.state()` 가 `{ page, step }` 을 돌려준다
- [ ] 자바스크립트가 필요한 쪽이 `HOOK[쪽 id]` 에 `step`·`reset` 을 등록했다

## 안정성 가드레일

`interaction-grammar.md` 의 아홉 가지와 원본 택소노미의 셋을 전 쪽에 적용한다.

- [ ] **칸 예약** — 나중에 켜지는 것의 자리가 정지 상태에도 잡혀 있다. 켜질 때 위의 것이 밀리지 않는다
- [ ] **늘어나는 방향** — 늘어나는 요소의 방향이 고정이고 그 방향에 여유가 있다
- [ ] **위치 이동 금지** — 등장은 투명도와 흐림으로만 한다. 꺼진 것도 자리를 차지하고 켜질 때 옆이 밀리지 않는다
- [ ] **넘침 제어** — 타일에 `overflow: hidden` 과 `min-width: 0` 이 있다. 긴 글자가 칸을 밀지 않는다
- [ ] **호버 반응** — 커서가 `pointer` 인 요소가 전부 호버에 반응한다. 반응 없는 `pointer` 가 하나도 없다
- [ ] **정적 폴백** — 인터랙션이 실패해도 보여 줄 정적 상태가 있다
- [ ] **쪽 되돌림** — 쪽을 떠나면 그 쪽이 처음 상태로 돌아간다. 되돌아가는 장면은 보이지 않는다
- [ ] **겹침 규율** — `z-index` 가 정해진 층에서만 쓰인다
- [ ] **넘김 계약** — 위 넘김 계약 항목과 같다
- [ ] **자기완결** — 서체와 이미지가 base64 로 인라인돼 있다. `src=` 와 `url()` 전수가 `data:` 로 시작한다. `tokens.css` 를 `<link>` 로 걸지 않았다

## 원고와 화면

- [ ] 화면의 글자가 원고와 한 글자도 다르지 않다 — 원고와 HTML 을 나란히 놓고 쪽마다 대조한다
- [ ] 줄바꿈이 원고가 정한 자리에서만 일어난다. 화면 폭 때문에 꺾인 줄이 없다
- [ ] 구현하며 발명한 이름이나 문장이 없다 — 원고에 없는 명사가 화면에 있으면 그것이 발명이다
- [ ] 수치와 예시에 예시 표기가 있다
- [ ] 출처가 필요한 주장에 출처가 화면에 있다

## 명세 이행

페이지 명세를 한 줄씩 짚으며 대조한다.

- [ ] 상태 — 항상 보이는 전역 상태가 명세가 정한 칸에 있다
- [ ] 시퀀스 — 단계 수와 각 단계에서 일어나는 일이 명세와 같다
- [ ] 상세 — 호버 미리보기와 클릭 고정이 짝으로 있다
- [ ] 해석 — 체험 뒤 takeaway 문장이 화면에 있다
- [ ] 폴백 — 명세가 정한 정적 상태가 실제로 구현돼 있다
- [ ] 등급 — 구현된 것이 명세의 등급과 같다. 구현하다 등급이 올라갔으면 명세를 고치는 것이 아니라 왜 올랐는지 따진다
