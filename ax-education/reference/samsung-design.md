# 삼성 디자인 언어 (실물 관찰)

사용자가 보여 준 삼성 화면 넷을 직접 보고 뽑았다. 색값과 서체 규정은 `samsung-brand.md`에 있고, 이 문서는 **화면을 어떻게 짜는가**를 다룬다. 이번 자료는 삼성 하면 떠오르는 그 결로 간다.

본 자료: 삼성벤처투자 사이트의 투자 분야 섹션, 갤럭시 Z 폴드8 제품 페이지 셋(히어로, 디자인 섹션, 디스플레이 섹션). 참고: https://design.samsung.com/kr/main/

## 1. 배경은 거의 흰색이고 카드가 없다

- 배경은 흰색이거나 아주 옅은 푸른끼 회색이다. 층을 카드로 만들지 않는다.
- 삼성벤처투자의 투자 분야 여덟 개는 4열 격자로 놓이는데 **카드도 테두리도 구분선도 없다.** 여백만으로 항목이 나뉜다.
- 이미지를 담는 면은 아주 큰 모서리 곡률을 쓴다. 화면 폭에 가깝게 크고 모서리가 넉넉히 둥글다.

## 2. 제목은 아주 굵고 아주 크다

- 영문 제목은 굵고 자간이 좁다. "The all-new Galaxy Z Fold8", "AI", "Robotics", "Device Solutions" 모두 같은 결이다.
- 한국어 제목도 굵다. "완벽하게 새로워진 디자인", "최적의 비율로, 즐거움을 최대로".
- 제목과 본문의 크기 차이가 크다. 제목이 크고 굵은 만큼 본문은 작고 얇다. 중간 크기가 별로 없다.

## 3. 정렬이 두 갈래로 분명하다

- **섹션 전체를 소개할 때는 가운데 정렬.** 삼성벤처투자의 투자 분야 여덟 개는 제목도 설명도 전부 가운데 정렬이고, 설명은 세 줄로 끊어 가운데를 맞춘다. "완벽하게 새로워진 디자인"도 가운데다.
- **기능을 설명할 때는 왼쪽 정렬.** 디스플레이 섹션은 왼쪽에 제목 두 줄, 오른쪽에 본문 문단이다.
- 섞지 않는다. 한 화면 안에서 정렬 축이 하나다.

## 4. 작은 파란 kicker

기능 섹션의 왼쪽 위에 "디스플레이" 같은 작은 파란색 라벨이 붙는다. 굵고 작다. 이 화면이 무엇을 말하는지 먼저 알린다.

**사용자의 기존 덱에도 같은 장치가 있다.** 왼쪽 위 작은 액센트 kicker는 삼성 화면과 사용자 관행이 만나는 지점이다.

## 5. 수치는 크게, 설명은 작게

- "10:16", "4:3" 같은 수치를 아주 크고 굵게, 강조색(파랑에서 보라로 기우는 계열)으로 놓는다.
- 수치 위에 아주 작은 라벨("화면비"), 아래에 두 줄짜리 작은 설명을 단다.
- 수치 옆에 작은 아이콘을 테두리 상자로 붙인다.

## 6. 본문은 짧은 줄로 끊는다

삼성벤처투자의 각 분야 설명은 세 줄로 끊겨 가운데 정렬돼 있다. 문장을 폭에 맡기지 않고 줄을 직접 나눈다. **사용자의 줄바꿈 철학과 정확히 같다.**

```
기반 기술과 응용 분야까지 AI 전반에
투자하며, 글로벌 시장에서 경쟁력을 갖춘
유망 스타트업에 투자합니다.
```

## 7. 색

- 화면의 뼈대는 흑백이다. 검정 제목, 회색 본문, 흰 배경.
- 강조는 파랑 계열 하나다. kicker와 수치에 쓴다.
- 히어로처럼 감성을 실을 때만 큰 면에 은은한 그라데이션을 깐다. 문서형 화면에는 쓰지 않는다.
- 버튼은 테두리만 있는 알약 형태가 쓰인다.

## 8. 이번 자료에 옮길 것

1. **기본은 배경 위에 직접 놓는다.** 카드와 테두리를 기본값으로 쓰지 않는다. 여백으로 나눈다.
2. **제목과 본문의 크기 차이를 크게 벌린다.** 중간 크기를 줄인다. 지금 목업이 제목 56과 카드 용어 56으로 같았던 것이 정확히 이 원칙을 어긴 것이다.
3. **한 화면에 정렬 축은 하나.** 개념을 세우는 화면은 가운데, 설명하는 화면은 왼쪽.
4. **왼쪽 위 작은 파란 kicker**를 페이지의 머리로 쓴다. 사용자 관행과도 맞는다.
5. **수치는 크게 강조색으로, 설명은 작게.**
6. **줄바꿈을 직접 끊는다.**
7. **흑백이 뼈대이고 파랑은 강조 하나.** Samsung Blue를 넓은 면에 깔지 않는다.
8. 이미지나 도해를 담는 면은 큰 곡률로.
