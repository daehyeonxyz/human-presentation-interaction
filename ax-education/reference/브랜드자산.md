# 확보한 브랜드 자산과 실측 팔레트

사용자가 삼성 공식 자산을 직접 제공했다. 자산은 `ax-education/assets/` 아래에 있다. 이 문서가 색과 서체의 최종 근거다.

## 확보한 파일

**로고** (`assets/lettermark/`)
- `Blue/Samsung_Orig_Wordmark_BLUE_RGB.png`, `Black/..._BLACK_RGB.png`, `White/..._WHITE_RGB.png`
- 각 색상별로 AI와 JPG도 있다. 화면에는 PNG를 쓴다.

**서체** (`assets/fonts/`, 웹용 변환본은 `assets/webfonts/`)
- SamsungSharpSans Bold / Medium / Regular. 영문 전용이고 woff2로 변환해 뒀다. 각 58KB 안팎이라 파일에 그대로 실을 수 있다.
- SamsungOneKorean 200부터 700까지, C 변형 포함. 국문 전용이고 굵기당 4MB 안팎이라 서브셋 없이는 못 싣는다.

**표지 배경** (`assets/cover-bg.jpg`)
- 사용자가 마음에 든다고 지목한 삼성미래기술육성사업 제안서 표지의 배경이다. 짙은 남색에서 파랑으로 흐르는 빛 리본이고 154KB다.

## 실측 팔레트 (삼성 공식 제안서 템플릿에서 추출)

사용자가 준 삼성 공식 2025 Business Proposal 템플릿 네 종의 슬라이드 XML에서 실제 사용된 색을 세어 뽑았다. 추정이 아니라 파일에서 읽은 값이다.

| 값 | 쓰임 |
|---|---|
| `#1428A0` | Samsung Blue. 네 템플릿 모두에서 상징색으로 등장한다 |
| `#000000` | 검정. 제목과 본문의 기본 |
| `#FFFFFF` | 흰색. 배경과 반전 텍스트 |
| `#0361E4` | 밝은 파랑. 강조와 링크 |
| `#3A8FFF` | 더 밝은 파랑. 보조 강조 |
| `#0020E1` `#0024FF` | 선명한 파랑. 좁은 면적의 강한 강조 |
| `#316AAD` | 가라앉은 파랑 |
| `#CFD9E5` | 옅은 청회색. 면과 구분 |
| `#FAFBFF` `#F4F5F9` | 푸른끼 도는 거의 흰 배경 |
| `#5B5B5B` `#6C6C6C` `#737373` | 본문 회색 계열 |
| `#B2B2B2` `#B7B7B7` | 비활성 회색 |

읽어 낼 것은 두 가지다. 첫째, **파랑 하나가 아니라 파랑 계열이 층으로 쓰인다.** 짙은 상징색 `#1428A0`, 밝은 강조 `#0361E4`, 더 밝은 보조 `#3A8FFF`, 옅은 면 `#CFD9E5`, 거의 흰 배경 `#FAFBFF`가 한 가족이다. 둘째, **회색이 정교하게 나뉜다.** 본문 회색과 비활성 회색이 다른 값이다.

## 서체 결정

**삼성 공식 제안서 템플릿이 쓰는 서체는 Pretendard다.** 네 파일 모두 Pretendard Medium, Regular, Bold, ExtraBold, Black을 쓴다. 사용자가 기본을 Pretendard로 하라고 한 지시와 삼성 공식 템플릿의 실제 선택이 일치한다.

그러므로 이렇게 간다.

- **국문과 기본 서체는 Pretendard다.** 굵기는 삼성 템플릿처럼 Medium, Bold, ExtraBold, Black까지 쓴다. 본문을 400으로 얇게 깔지 않는다.
- **영문 표시용은 SamsungSharpSans를 쓴다.** 제목의 영문, 큰 수치, 라벨처럼 삼성다움이 드러나야 하는 자리다. woff2로 준비돼 있어 파일에 실을 수 있다.
- SamsungOneKorean은 굵기당 4MB라 지금은 쓰지 않는다. 필요하면 쓰이는 글자만 골라 서브셋해 실을 수 있다.

## 표지 방향 (사용자 지목)

사용자가 마음에 든다고 한 표지는 이렇게 생겼다.

- 화면 전체가 짙은 남색에서 파랑으로 흐르는 빛 리본 배경이다.
- 왼쪽 위에 흰색 로고와 사업 이름이 두 줄로 작게 놓인다.
- 오른쪽 위에 영문 대문자 한 줄이 자간을 벌려 작게 놓인다.
- 가운데에 큰 흰색 한국어 제목이 있고 바로 아래에 영문 태그라인이 온다.
- 오른쪽 아래 구석에 영문 세 줄이 작게 놓인다.

AX 101 표지도 이 구조로 간다. 배경은 `assets/cover-bg.jpg`, 왼쪽 위에 흰색 삼성 워드마크, 가운데에 큰 제목, 아래에 영문 한 줄이다.

## 삼성 로고 사용 규정

레터마크 색은 삼성 블루(`#1428A0`, PMS 286C), 블랙(`#000000`), 화이트(`#FFFFFF`) 셋뿐이다. 밝은 배경에는 블루나 블랙, 어두운 배경과 파란 면에는 화이트를 쓴다. 직접 그리지 않고 받은 PNG를 그대로 쓴다.
